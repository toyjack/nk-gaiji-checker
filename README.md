# nk-gaiji-checker

Empty Next.js project scaffold.

## Development

```bash
pnpm dev
```

The current glyph can be displayed as either `/images/{ORGCODE}.gif` or
`/png-images/{GID}.png` (for example, `/png-images/G033360.png`). For local
development, place the corresponding files in `public/images/` and
`public/png-images/`, or configure your server to serve those paths.
